🧠 Core Concepts Covered in the PDF

1. Data Matrix:

A data matrix is just a table where:

  • Rows typically represent examples (like students, emails, or products).

  • Columns represent features or attributes (like height, age, price, etc).

👁️‍🗨️ Views: Attribute View vs. Point View

This is about how you look at a matrix — from two different perspectives:

📍 Point View:

  • Here, each column vector in the matrix is seen as a data point in a high-dimensional space.

  • You're thinking: “Each column is a point, made up of numbers.”

🎯 Attribute View:

  • In this view, each row is treated as a feature (or attribute).

  • You're thinking: “Each row is a direction or axis in space.”

✅ What’s important:

  • All vectors are considered as column vectors (vertical).

  • In attribute view, the vectors (features) are orthogonal—this means they are at right angles to each other, and independent.

📏 Norm, Distance, and Angle

These are geometric ideas applied to vectors:

🔹 Norm/Length/Magnitude of a Vector:

  • It tells you how long a vector is.

  • Think of it as the "size" or "energy" of the data point.

  • It's calculated like the length of a line:

    ∥v∥=v12+v22+...+vn2\|v\| = \sqrt{v_1^2 + v_2^2 + ... + v_n^2}∥v∥=v12​+v22​+...+vn2​​

🔹 Distance between vectors (Target vs. Predicted):

  • If you have a true (target) value and a predicted one, the distance between them tells you how close your prediction is.

  • The smaller the distance, the better the prediction.

🔹 Angle between Vectors:

  • Shows how similar two vectors are in direction.

  • If angle = 0°, they point the same way → very similar.

  • If angle = 90°, they’re completely unrelated (orthogonal).

  • If angle = 180°, they point in opposite directions → very different.

➕ Mean:

  • The average value of data points or attributes.

  • Used in various calculations like centering data (subtracting mean before processing).
