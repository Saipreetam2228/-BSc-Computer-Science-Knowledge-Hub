🌟 What Is an Artificial Neural Network (ANN)?

An Artificial Neural Network (ANN) is a computational model inspired by the human brain.
Just like our brain has neurons that process signals, an ANN has artificial neurons (nodes) that process data.

It’s mainly used for:

  • Pattern recognition

  • Classification and prediction

  • Data clustering and mining relationships in data

In data mining, ANNs help discover hidden patterns or predict outcomes from large datasets — for example, predicting customer churn, detecting fraud, or classifying emails as spam/not spam.

🧠 Structure of an ANN

An ANN is composed of three main layers:

1. Input Layer

  • Takes the raw data features (like age, salary, temperature, pixel values, etc.)

  • Each neuron in this layer represents one input variable.

2. Hidden Layers

  • These layers process the data using weights and activation functions.

  • They learn complex patterns or non-linear relationships in the data.

  • More hidden layers → more learning power (this becomes Deep Learning when there are many layers).

3. Output Layer

  • Produces the final result, such as:

    • Class label (Yes/No, 0/1)

    • Continuous value (like predicting house price)

⚙️ How Does an ANN Work? — Step by Step

Let’s go step-by-step in simple terms 👇

1. Input Data

Data features are fed into the network.

Example:
If we are predicting if a student passes based on hours studied and attendance,
then x1 = hours studied, x2 = attendance.

2. Weighted Sum (Forward Propagation)

Each input is multiplied by a weight (w), and then all are added together along with a bias (b).

z=(x1×w1)+(x2×w2)+bz = (x_1 \times w_1) + (x_2 \times w_2) + bz=(x1​×w1​)+(x2​×w2​)+b

Weights tell how important each input is.
Bias helps adjust the output independently of inputs.

3. Activation Function

The sum z is passed through an activation function to introduce non-linearity, meaning the model can learn complex patterns, not just straight lines.

Common activation functions:

  • Sigmoid → output between 0 and 1 (used for probability)

  • ReLU (Rectified Linear Unit) → faster, used in deep learning

  • tanh → output between -1 and +1

Example (Sigmoid):

a=11+e−za = \frac{1}{1 + e^{-z}}a=1+e−z1​

4. Output

The activated value a passes to the next layer (or becomes the final prediction if it’s the output layer).

5. Error Calculation (Loss Function)

Compare the network’s output with the actual/target value to find the error.

Example:

Error=(Predicted Output−Actual Output)2\text{Error} = (\text{Predicted Output} - \text{Actual Output})^2Error=(Predicted Output−Actual Output)2

6. Backward Propagation (Learning)

Now the ANN learns from its mistakes:

  • The error is sent back through the network (backpropagation).

  • Each weight is adjusted slightly to reduce the error using a method called Gradient Descent.

Formula (for updating weights):

wnew=wold−η×∂Error∂ww_{new} = w_{old} - \eta \times \frac{\partial \text{Error}}{\partial w}wnew​=wold​−η×∂w∂Error​

Where η (eta) is the learning rate, controlling how fast the model learns.

7. Iteration (Training)

This process (forward + backward propagation) repeats for many epochs (iterations) until:

  • The error is minimized

  • The ANN learns to predict accurately

The classic perceptron:

  • Learns offline (trained on fixed data, not live)

  • Has no mechanism to adapt continuously

  • Cannot handle noise or non-linear patterns

Question 2: What type of task is performed by the Perceptron Algorithm (PA) and which decision boundary is used for the task?

Answer:

The Perceptron Algorithm (PA) is primarily designed to perform binary classification tasks in the field of machine learning and data mining.
It belongs to the family of supervised learning algorithms, where the model learns from labeled training data to classify new or unseen examples into one of two possible categories.

1️⃣ Type of Task Performed by the Perceptron Algorithm

The main task performed by the Perceptron is classification, especially linearly separable binary classification.

➤ Explanation:

In a classification problem, the goal is to assign an input vector x=(x1,x2,...,xn)x = (x_1, x_2, ..., x_n)x=(x1​,x2​,...,xn​) to one of two output classes, usually represented as:

y=+1ory=−1y = +1 \quad \text{or} \quad y = -1y=+1ory=−1

The perceptron takes a set of input features, applies certain weights, and determines to which class the input belongs by computing a weighted sum and applying a threshold function (also called a step or sign function).

Mathematically, this can be written as:

h(x)=w⋅x+bh(x) = w \cdot x + bh(x)=w⋅x+b

Then, the decision rule is:

y^={+1,if h(x)>0−1,if h(x)≤0\hat{y} = \begin{cases} +1, & \text{if } h(x) > 0 \\ -1, & \text{if } h(x) \leq 0 \end{cases}y^​={+1,−1,​if h(x)>0if h(x)≤0​

Thus, the perceptron separates data points into two classes based on which side of the decision boundary they fall on.

2️⃣ Decision Boundary Used for the Task

The decision boundary used by the Perceptron is a linear decision boundary.
It represents a hyperplane that divides the input space into two distinct regions — one for each class.

➤ Mathematical Form of the Decision Boundary:

w1x1+w2x2+⋯+wnxn+b=0w_1x_1 + w_2x_2 + \dots + w_nx_n + b = 0w1​x1​+w2​x2​+⋯+wn​xn​+b=0

  • w=(w1,w2,...,wn)w = (w_1, w_2, ..., w_n)w=(w1​,w2​,...,wn​) are the weights (they determine the orientation of the boundary),

  • bbb is the bias (it determines the position or offset of the boundary from the origin),

  • x=(x1,x2,...,xn)x = (x_1, x_2, ..., x_n)x=(x1​,x2​,...,xn​) is the input vector.

This equation defines a hyperplane in n-dimensional space.

  • In 2D, the boundary is a straight line.

  • In 3D, it is a plane.

  • In higher dimensions, it becomes a hyperplane.

3️⃣ Working Principle of the Decision Boundary

The perceptron classifies the input based on the sign of the function h(x)=w⋅x+bh(x) = w \cdot x + bh(x)=w⋅x+b:

  • If h(x)>0h(x) > 0h(x)>0: The input lies on one side of the hyperplane → class +1

  • If h(x)<0h(x) < 0h(x)<0: The input lies on the other side → class -1

Thus, the decision boundary acts as a separator between two groups of data points in the input feature space.

yi(w⋅xi+b)>0y_i (w \cdot x_i + b) > 0yi​(w⋅xi​+b)>0

5️⃣ Theoretical Importance of the Decision Boundary

  • The decision boundary in the perceptron defines the region of separation between the two classes.

  • It allows the model to make a deterministic prediction for any new data point.

  • It represents a linear discriminant function, which is the foundation for more advanced algorithms like Support Vector Machines (SVMs) and Multi-Layer Perceptrons (MLPs).

  • The perceptron converges (finds an optimal hyperplane) only if the data is linearly separable.
